## 🧭 About Me

I'm a **Data Engineer and Full Stack Engineer** passionate about building production-ready systems that move data efficiently and solve real operational problems. I enjoy the entire engineering lifecycle — from **ingesting and transforming data**, to **building event-driven pipelines**, to **developing web applications and dashboards** that make data actionable.

My work focuses on **reliability, scalability, automation, and maintainability**, with an emphasis on practical solutions that can be deployed and used in real-world environments.

- 🏗️ **Data Engineering** — ETL/ELT pipelines, data ingestion, transformation, workflow automation, and streaming architectures
- ⚡ **Streaming Systems** — Apache Kafka, event-driven processing, and real-time data pipelines
- ⚙️ **Backend Engineering** — Python, FastAPI, Node.js, Express.js, authentication, APIs, and webhook integrations
- 🖥️ **Full Stack Development** — Next.js, React, TypeScript, and modern web application architecture
- 📊 **Analytics Engineering** — SQL, dbt, Snowflake, Databricks, Power BI, DAX, and data modeling

> I believe the best software is software that people can depend on — well designed, well documented, and built with real constraints in mind.
