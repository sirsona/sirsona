## 🧭 About Me

I'm a data engineer and full-stack developer who enjoys the whole journey — from **ingesting raw data and building ETL/ELT pipelines**, to **streaming real-time events**, to **shipping the dashboards and web apps** that make the data useful.

- 🏗️ **Data Engineering** — batch & event-driven pipelines, Kafka streaming, SQL modeling, workflow automation
- ⚙️ **Backend** — Python & Node.js APIs (FastAPI, Express), authentication, webhook integrations
- 🖥️ **Frontend** — Next.js, React, TypeScript — interfaces that work in the real world
- 📊 **Analytics** — Power BI, DAX, data modeling, and SQL for decisions

> I believe the best systems are the ones that actually get used — reliable, documented, and built with real constraints in mind.
