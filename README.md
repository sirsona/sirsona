## 🧭 About Me

I'm a data engineer and full-stack developer who enjoys the whole journey — from **ingesting raw data and building ETL/ELT pipelines**, to **streaming real-time events**, to **shipping the dashboards and web apps** that make the data useful.

My work spans the full stack:

- **Data Engineering** — batch & event-driven pipelines, Kafka streaming, SQL modeling, workflow automation
- **Backend** — Python & Node.js APIs (FastAPI, Express), authentication, webhook integrations
- **Frontend** — Next.js, React, TypeScript — interfaces that work in the real world
- **Analytics** — Power BI, DAX, data modeling, and SQL for decisions

> I believe the best systems are the ones that actually get used — reliable, documented, and built with real constraints in mind.

## 📌 Featured Projects

### [Sirsona Shop](https://github.com/sirsona/sirsona-shop)
Full-stack e-commerce platform built with **Next.js 14 (App Router), Express 5, and PostgreSQL** — featuring **Paystack payments with signed webhook verification**, Twilio WhatsApp notifications, and an admin dashboard.

### [Weather Event Streaming](https://github.com/sirsona/weather-event-streaming)
Real-time weather event pipeline using **Python, Confluent Cloud Kafka, and the OpenWeather API** — streaming live weather events into a Kafka topic.

### [Japan Cars Import — Price Prediction](https://github.com/sirsona/japan-cars-import)
Machine learning system that **predicts used-car prices** using web scraping, **XGBoost & Random Forest regression**, and Jupyter notebooks.

### [SQL Sales Analysis](https://github.com/sirsona/sales-inventory-sql-part1)
SQL projects on **PostgreSQL** — sales analysis, window functions, joins, and inventory queries for practical business insight.

### [Power BI Guides](https://github.com/sirsona/Schema-And-Data-Modelling-in-Power-BI)
Published guides on **schema & data modeling in Power BI**, DAX dashboards, and connecting Power BI to PostgreSQL — shared with the community on dev.to.
